# realsubway

地铁规划模拟游戏。灵感来自 [Brand New Subway](https://jpwright.github.io/subway/) 与 [Subway Builder](https://www.subwaybuilder.com),目标是在真实地图上画线建站,模拟一个运营日的出行,并以 **运输总量 / 经济利润 / 综合评分** 三参数评价线网。

目前版本限于北京地图，人口参数暂定来源于北京。随着版本更新会拓展到全国/全球数据

## 开发

```bash
npm install
npm run dev        # 开发服务器 (端口 5180)
npm test           # vitest 单元测试
npm run typecheck  # tsc --noEmit
npm run build      # 产物可静态托管(如 GitHub Pages)
```

## 结构

```
tools/        Python 离线数据管线(人口/吸引栅格、现网数据)
src/model/    线网数据模型(站/线/服务计划/车型)
src/sim/      模拟引擎,跑在 Web Worker(需求→方式选择→分配→容量截断)
src/render/   MapLibre GL 图层(线网、列车、热力)
src/ui/       线路面板、车站弹窗、服务计划编辑器、时钟
src/persist/  localStorage 自动存档 + JSON 导入导出
```

## 路线图

- [x] **M1 画线建站**:地图上建站、铺线、并线换乘、改名删除;自动存档与导入导出
- [x] **M2 真实数据管线 + 静态客流**:WorldPop 人口栅格 + OSM 吸引栅格/地标/现网提取;站点核采样客流、全网合计、需求热力图
- [x] **M3 出行结构**:引力模型 OD + 线路扩展图 Dijkstra 分配(Web Worker);站点进出站量、区间断面/高峰弹窗;现网验证(繁忙线排名符合现实)
- [x] **M4 运营模拟**(三部分)
  - [x] 服务计划编辑器:首末班车、逐小时间隔滑条、车型(A/B/C)×编组
  - [x] 时刻表与容量:模拟时钟(1×/60×/600×)+ 列车动画;逐小时运力截断 → 运输总量、未送达、满载率;末班车后需求流失
  - [x] 通勤方式选择:潜在需求 × logit 分担(地铁广义时间 vs 替代方式),面板显示地铁分担率——服务改善会真实吸引新乘客
- [x] **M4X 车站自动取名**:点击建站按位置取地道中文名(可手改)——真实站名 → 地标(带方位)→ OSM 片区名回退,重名消歧(道路/路口命名列为二期)
- [ ] **M5 经济与评分**:票款(里程计价)、运营成本(车公里+车站)、建设摊销;综合字母评分 headless 标定(真实现网 ≈ B);三参数日报面板
- [ ] **M6 开局与打磨**:开局模式(空白/从现网开始)、多存档、轨道曲线渲染、移动端窄屏、性能压测(30线×600站,重算<200ms)、GitHub Pages 部署
